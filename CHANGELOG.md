Date: November 12, 2025
Title: 🗂 “Routes Cleanup & Import Optimization”

Description:
Refactored the front-end routing structure by creating a dedicated `routes.js` file to centralize all route definitions. Removed unused imports from `App.js` to improve code clarity. Updated `App.js` to dynamically map over the routes array, resulting in a cleaner and more maintainable codebase. This improvement reduces the risk of import clutter, simplifies future updates, and makes the project easier for contributors to navigate and scale. The app functionality remains unchanged while enhancing readability and maintainability for ongoing development.
